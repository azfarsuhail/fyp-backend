Powered by Multi-Agent AI

Seamlessly bridging intuitive mobile design with a high-performance cloud infrastructure to protect patients and deliver accuracy.

Intelligent Gatekeeper

Instantly validates camera uploads. The MobileNetV2 agent ensures only valid knee X-rays are processed, rejecting irrelevant images automatically to prevent false diagnostics.

Clinical CNN Grading

Evaluates the image using a custom-trained Convolutional Neural Network deployed on AWS to calculate an accurate Kellgren-Lawrence severity score (0-4).

Parametric RAG Therapy

The Recommendation Agent cross-references your diagnosis with your specific medical history to deliver safe, contraindicated exercise protocols and video guides.

Designed for the Real World

Bridging the gap between patient care at home and rapid triage in the clinic.

For Patients

  • Symptom Tracking: Log daily pain levels and joint mobility via an intuitive questionnaire.
  • Home Exercise Library: Receive personalized, safe video exercises tailored to your specific mobility level.
  • Condition Management: Take control of your preventive care before reaching late-stage disability.

For General Practitioners

  • Rapid Triage: Upload PA X-rays for an instant, unbiased second opinion on KL severity.
  • Standardized Reporting: Generate automated diagnostic summaries for patient records.
  • Secure & Scalable: Data is handled securely via AWS S3 and PostgreSQL, matching modern compliance standards.

Engineering Architecture

Decoupled Microservices • Automated CI/CD • Scalable ML Inference

Backend Infrastructure

Powered by an asynchronous FastAPI layer, protected by JWT authentication and Role-Based Access Control (RBAC). API traffic is reverse-proxied through NGINX.

Python 3.10 FastAPI Docker

Multi-Agent Inference

Uses a custom-trained TensorFlow CNN for image analysis and a Sentence-Transformers engine for Retrieval-Augmented Generation (RAG) to fetch clinical advice.

TensorFlow Vector DB OpenCV

Cloud Data Layer

Relational data is managed via SQLAlchemy 2.0 on a serverless Neon DB (PostgreSQL). High-volume media (X-rays, MP4s) are securely persisted in AWS S3.

PostgreSQL AWS S3 Alembic
